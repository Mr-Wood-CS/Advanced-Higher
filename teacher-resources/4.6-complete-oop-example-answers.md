# Teacher Answers — Complete OOP Example

This file is outside `docs` and is not included in the pupil site.

1. `Person` is the superclass. `Pupil` and `Teacher` are subclasses.
2. `__attendance` is private. `set_attendance()` and `get_attendance()` control access.
3. Inheritance occurs in `class Pupil(Person):` and `class Teacher(Person):`. Both subclasses call the superclass initialiser using `super().__init__(name)`.
4. The loop calls `display_details()` on pupil and teacher objects. The object type determines which implementation runs.
5. Example extension:

    ```python
    class SupportStaff(Person):

        def __init__(self, name, role):
            super().__init__(name)
            self.role = role

        def display_details(self):
            print("Support staff:", self.name)
            print("Role:", self.role)
    ```

    Add this object to the `people` array:

    ```python
    SupportStaff("Mr Jones", "Technician")
    ```
