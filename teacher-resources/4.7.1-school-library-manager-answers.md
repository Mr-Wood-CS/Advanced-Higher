## Analysis

Example purpose:

> To manage the availability and borrowing of books and DVDs in a school library.

| Inputs | Processes | Outputs |
|---|---|---|
| Item ID | Create item objects | Item details |
| Borrowing choice | Traverse objects to match an ID | Borrowing confirmation |
| Item details used during setup | Check availability | Unavailable-item message |
|  | Update availability | Invalid-ID message |

## Example Functional Requirements

The program must:

1. create and store book and DVD objects
2. store a unique ID and title for every item
3. store availability privately
4. display details appropriate to each item type
5. allow an available item to be borrowed
6. prevent an unavailable item from being borrowed
7. allow an item to be returned
8. explain when an entered ID does not match an item

## Complete Python Solution

```python
class LibraryItem:

    def __init__(self, item_id, title):
        self.item_id = item_id
        self.title = title
        self.__available = True

    def get_available(self):
        return self.__available

    def borrow_item(self):
        if self.__available:
            self.__available = False
            print(self.title, "has been borrowed.")
        else:
            print(self.title, "is not available.")

    def return_item(self):
        self.__available = True
        print(self.title, "has been returned.")

    def display_details(self):
        print("ID:", self.item_id)
        print("Title:", self.title)
        print("Available:", self.__available)


class Book(LibraryItem):

    def __init__(self, item_id, title, author):
        super().__init__(item_id, title)
        self.author = author

    def display_details(self):
        print("BOOK")
        print("ID:", self.item_id)
        print("Title:", self.title)
        print("Author:", self.author)
        print("Available:", self.get_available())


class DVD(LibraryItem):

    def __init__(self, item_id, title, duration):
        super().__init__(item_id, title)
        self.duration = duration

    def display_details(self):
        print("DVD")
        print("ID:", self.item_id)
        print("Title:", self.title)
        print("Duration:", self.duration, "minutes")
        print("Available:", self.get_available())


items = [
    Book("B101", "The Hobbit", "J. R. R. Tolkien"),
    Book("B102", "Coraline", "Neil Gaiman"),
    DVD("D201", "Inside Out", 95),
    DVD("D202", "Hidden Figures", 127)
]


def display_items(items):
    for item in items:
        item.display_details()
        print()


def borrow_by_id(items, target_id):
    found = False

    for item in items:
        if item.item_id == target_id:
            item.borrow_item()
            found = True

    if not found:
        print("Item ID not found.")


display_items(items)

target_id = input("Enter the item ID to borrow: ").upper()
borrow_by_id(items, target_id)

display_items(items)
```
