## Check Your Understanding

1. The class is `GameCharacter`, the object variable is `player1`, the properties are `username` and `health`, and the method is `display_status()`.
2. `__init__` gives a newly created character its initial property values. It stores the supplied username and health inside the new object.
3. `self` refers to the particular object that called the method. In this call, it refers to the object stored in `player1`.
4. The output is:

    ```text
    SkyRunner 100
    ```

5. The health can be updated and displayed using:

    ```python
    player1 = GameCharacter("SkyRunner", 100)
    player1.display_status()

    player1.health = 75
    player1.display_status()
    ```

    Expected output:

    ```text
    SkyRunner 100
    SkyRunner 75
    ```
