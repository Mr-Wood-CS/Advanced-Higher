## Task 1 — Reading Indexes

| Element | Value |
|---|---:|
| `temperatures[0][2]` | `13` |
| `temperatures[1][3]` | `17` |
| `temperatures[2][0]` | `10` |

Indexes start at zero: the first index selects the row and the second selects the column.

```python
temperatures = [
    [12, 14, 13, 15],
    [11, 13, 16, 17],
    [10, 12, 14, 16]
]

print(temperatures[0][2])
print(temperatures[1][3])
print(temperatures[2][0])
```

## Task 2 — Cinema Seats

```python
seats = [
    ["A", "A", "B", "A", "A"],
    ["A", "B", "A", "A", "A"],
    ["A", "A", "A", "B", "A"],
    ["B", "A", "A", "A", "A"]
]

print("Current seating plan:")
for row in seats:
    print(" ".join(row))

try:
    row = int(input("Enter row (0-3): "))
    column = int(input("Enter column (0-4): "))
except ValueError:
    print("Row and column must be whole numbers.")
else:
    if 0 <= row < len(seats) and 0 <= column < len(seats[row]):
        if seats[row][column] == "A":
            seats[row][column] = "B"
            print("Seat booked successfully.")
        else:
            print("That seat is already booked.")
    else:
        print("That position is outside the seating plan.")

print("Updated seating plan:")
for row in seats:
    print(" ".join(row))
```

Example: enter row `0` and column `0`. The program reports `Seat booked successfully.` and displays:

```text
Updated seating plan:
B A B A A
A B A A A
A A A B A
B A A A A
```

Additional checks (restart the program for each):

| Row | Column | Expected result |
|---|---|---|
| `0` | `2` | Seat already booked; plan unchanged. |
| `-1` | `0` | Position outside the seating plan. |
| `4` | `0` | Position outside the seating plan. |
| `0` | `5` | Position outside the seating plan. |
| `hello` | — | Whole-number error; plan unchanged. |

The bounds check runs before accessing the selected seat. This also prevents Python's negative indexes from selecting seats at the end of the array.

## Task 3 — Rainfall Analysis

```python
rainfall = [
    [42, 38, 51, 47],
    [35, 41, 39, 44],
    [50, 48, 46, 53]
]

total = 0
number_of_values = 0
highest = rainfall[0][0]

for row in rainfall:
    for value in row:
        total += value
        number_of_values += 1
        if value > highest:
            highest = value

average = total / number_of_values
print("Total rainfall:", total)
print(f"Average rainfall: {average:.2f}")

for row in range(len(rainfall)):
    town_total = 0
    for column in range(len(rainfall[row])):
        town_total += rainfall[row][column]
    print(f"Town {row + 1} total: {town_total}")

print("Highest rainfall:", highest)
```

Expected results:

- total: `534`
- average: `44.50`
- town totals: `178`, `159`, `197`
- highest: `53`
