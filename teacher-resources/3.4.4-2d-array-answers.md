## Task 1 — Reading Indexes

| Element | Value |
|---|---:|
| `temperatures[0][2]` | `13` |
| `temperatures[1][3]` | `17` |
| `temperatures[2][0]` | `10` |

Indexes start at zero: the first index selects the row and the second selects the column.

```python
temperatures = [
    [12, 14, 13, 15],
    [11, 13, 16, 17],
    [10, 12, 14, 16]
]

print(temperatures[0][2])
print(temperatures[1][3])
print(temperatures[2][0])
```

## Task 2 — Cinema Seats

```python
seats = [
    ["A", "A", "B", "A", "A"],
    ["A", "B", "A", "A", "A"],
    ["A", "A", "A", "B", "A"],
    ["B", "A", "A", "A", "A"]
]

print("Current seating plan:")
for row in seats:
    for seat in row:
        print(seat, end=" ")
    print()

row = int(input("Enter row (0-3): "))
column = int(input("Enter column (0-4): "))

if row >= 0 and row <= 3 and column >= 0 and column <= 4:
    if seats[row][column] == "A":
        seats[row][column] = "B"
        print("Seat booked successfully.")
    else:
        print("That seat is already booked.")
else:
    print("Invalid position. Enter a row from 0 to 3 and a column from 0 to 4.")

print("Updated seating plan:")
for row in seats:
    for seat in row:
        print(seat, end=" ")
    print()
```

Example: enter row `0` and column `0`. The program reports `Seat booked successfully.` and displays:

```text
Updated seating plan:
B A B A A
A B A A A
A A A B A
B A A A A
```

Additional checks (restart the program for each):

| Row | Column | Expected result |
|---|---|---|
| `0` | `2` | Seat already booked; plan unchanged. |
| `-1` | `0` | Invalid position; plan unchanged. |
| `4` | `0` | Invalid position; plan unchanged. |
| `0` | `5` | Invalid position; plan unchanged. |

This example assumes the user enters whole numbers. Selection checks that the row is between 0 and 3 and the column is between 0 and 4 before accessing the selected seat.

## Task 3 — Rainfall Analysis

```python
rainfall = [
    [42, 38, 51, 47],
    [35, 41, 39, 44],
    [50, 48, 46, 53]
]

total = 0
number_of_values = 0
highest = rainfall[0][0]

for row in rainfall:
    for value in row:
        total = total + value
        number_of_values = number_of_values + 1
        if value > highest:
            highest = value

average = total / number_of_values
print("Total rainfall:", total)
print("Average rainfall:", average)

for row in range(len(rainfall)):
    town_total = 0
    for column in range(len(rainfall[row])):
        town_total = town_total + rainfall[row][column]
    print("Town", row + 1, "total:", town_total)

print("Highest rainfall:", highest)
```

Expected results:

- total: `534`
- average: `44.5`
- town totals: `178`, `159`, `197`
- highest: `53`
