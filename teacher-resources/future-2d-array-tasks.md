# Future Two-Dimensional Array Tasks

These tasks have been held back until pupils have covered searching and more complex array processing. They are outside the `docs` directory and will not appear on the pupil site.

## Searching a Warehouse

Create a two-dimensional array containing product codes arranged by shelf and position. Ask the user for a product code, search the entire array and display its shelf and position. Display a suitable message if the code is absent.

Extend your program so the search is not case-sensitive.

**Run and test your program, then add printscreens showing your code and the output from both a successful and an unsuccessful search to your workbook.**

## Connect Three

Create a 5 × 5 board filled with `"-"`. Allow two players to place `"X"` and `"O"` in turn.

Your program should:

- display the board before each turn
- ask for a row and column
- reject positions outside the board
- reject occupied positions
- update a valid position
- swap player after a valid move

**Run and test your program, then add a printscreen of your code and output to your workbook. Your output should demonstrate at least one invalid move and several valid moves.**

### Extension — Detect a Winner

After each valid turn, determine whether the current player has three matching symbols in a horizontal, vertical or diagonal line.

**Run and test the extension, then add a printscreen of your code and output showing a winning line to your workbook.**

Solutions are retained in `teacher-resources/3.4.4-2d-array-answers.md` under Tasks 4 and 5.
