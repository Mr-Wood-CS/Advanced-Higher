# Teacher Answers — Polymorphism

This file is outside `docs` and is not included in the pupil site.

1. `Notification` is the superclass. `EmailNotification` and `TextNotification` are the subclasses.
2. `send()` is overridden.
3. The loop makes the same `send()` call on different objects, and each object's class selects a different implementation.
4. The output is `Sending email`, followed by `Sending text message`.
5. Example extension:

    ```python
    class AppNotification(Notification):

        def send(self):
            print("Sending app notification")


    notifications = [
        EmailNotification(),
        TextNotification(),
        AppNotification()
    ]
    ```
