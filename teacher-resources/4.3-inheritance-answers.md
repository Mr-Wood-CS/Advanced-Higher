# Teacher Answers — Inheritance and Subclasses

This file is outside `docs` and is not included in the pupil site.

1. `LibraryItem` is the superclass and `Book` is the subclass.
2. `title` and `display_title()` are inherited. `author` is defined by `Book`.
3. `super().__init__(title)` calls the `LibraryItem` initialiser and stores the title in the new object.
4. The output is `The Hobbit`, followed by `J. R. R. Tolkien`.
5. Example extension:

    ```python
    class DVD(LibraryItem):

        def __init__(self, title, duration):
            super().__init__(title)
            self.duration = duration


    dvd1 = DVD("Inside Out", 95)
    dvd1.display_title()
    print(dvd1.duration)
    ```
