# Teacher Answers — Arrays of Objects

This file is outside `docs` and is not included in the pupil site.

1. Three objects are stored in `books`.
2. The expression is `books[1].title`.
3. On each pass, `book` refers to the next complete `Book` object in the array.
4. The output is:

    ```text
    The Hobbit 310
    Coraline 192
    Noughts & Crosses 496
    ```

5. Example extension:

    ```python
    books.append(Book("A Monster Calls", 237))

    for book in books:
        book.display_details()
    ```
