# SQLite with Python

!!! info "What You Need to Know"

    You must be able to describe, exemplify and implement code that:

    - opens and closes a connection to a database
    - executes an SQL query
    - formats query results

## The Database Programming Sequence

A database program normally follows four steps:

1. open a connection
2. create a cursor and execute an SQL statement
3. process and format any results
4. close the connection

Python includes the `sqlite3` module, so no additional package is required.

## Opening a Connection

```python title="Connect to a Database" linenums="1"
import sqlite3

connection = sqlite3.connect("school.db")
cursor = connection.cursor()
```

If `school.db` does not exist, SQLite creates it. The cursor is used to send SQL statements to the database.

## Creating a Table

This setup code creates a table for the examples on this page:

```python title="Create the Pupil Table" linenums="1"
cursor.execute("""
    CREATE TABLE IF NOT EXISTS pupil (
        pupil_id INTEGER PRIMARY KEY,
        name TEXT NOT NULL,
        age INTEGER NOT NULL,
        registration_group TEXT NOT NULL
    )
""")

connection.commit()
```

`commit()` permanently saves a change made by `CREATE`, `INSERT`, `UPDATE` or `DELETE`.

## Executing an INSERT Statement

Use placeholders for values supplied by the program:

```python title="Insert One Record" linenums="1"
name = input("Enter name: ")
age = int(input("Enter age: "))
registration_group = input("Enter registration group: ")

cursor.execute(
    "INSERT INTO pupil (name, age, registration_group) VALUES (?, ?, ?)",
    (name, age, registration_group)
)

connection.commit()
```

!!! warning "Use Parameters"

    Do not build an SQL statement by joining user input into a string. Placeholders keep data separate from the SQL command and help prevent SQL injection.

## Retrieving and Formatting Results

```python title="Display Query Results" linenums="1"
cursor.execute("""
    SELECT pupil_id, name, age, registration_group
    FROM pupil
    ORDER BY name
""")

rows = cursor.fetchall()

for row in rows:
    print(f"ID: {row[0]}")
    print(f"Name: {row[1]}")
    print(f"Age: {row[2]}")
    print(f"Registration group: {row[3]}")
    print()
```

`fetchall()` returns the result set as a list of rows. Each field in a row is accessed by its position.

## A Parameterised SELECT Statement

A one-item tuple requires a trailing comma:

```python title="Select One Pupil" linenums="1"
target_name = input("Enter a name: ")

cursor.execute(
    "SELECT pupil_id, name, age, registration_group FROM pupil WHERE name = ?",
    (target_name,)
)

row = cursor.fetchone()

if row is None:
    print("Pupil not found.")
else:
    print(row[1], row[2], row[3])
```

## Updating and Deleting Data

```python title="Update a Record" linenums="1"
cursor.execute(
    "UPDATE pupil SET registration_group = ? WHERE pupil_id = ?",
    ("R3", 2)
)
connection.commit()
```

```python title="Delete a Record" linenums="1"
cursor.execute("DELETE FROM pupil WHERE pupil_id = ?", (2,))
connection.commit()
```

## Storing Results in an Array of Records

Query results can be converted into the record structure studied earlier:

```python title="Convert Rows to Records" linenums="1"
from dataclasses import dataclass


@dataclass
class PupilRecord:
    pupil_id: int
    name: str
    age: int
    registration_group: str


cursor.execute("""
    SELECT pupil_id, name, age, registration_group
    FROM pupil
    ORDER BY name
""")

pupils = [PupilRecord(*row) for row in cursor.fetchall()]

for pupil in pupils:
    print(pupil.name, pupil.registration_group)
```

The order of the selected fields must match the order of the fields in `PupilRecord`.

## Closing the Connection

Always close the database connection when it is no longer required:

```python
connection.close()
```

## Complete Read-Only Example

```python title="Connect, Query, Format and Close" linenums="1"
import sqlite3

connection = sqlite3.connect("school.db")
cursor = connection.cursor()

cursor.execute("SELECT name, age FROM pupil ORDER BY name")
rows = cursor.fetchall()

for row in rows:
    print(f"{row[0]} is {row[1]} years old.")

connection.close()
```
