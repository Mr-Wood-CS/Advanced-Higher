## Task 1 — Reading Indexes

```python

    [12, 14, 13, 15],
    [11, 13, 16, 17],
    [10, 12, 14, 16]
]
```

Without running the code, state the values at:

- `temperatures[0][2]`
- `temperatures[1][3]`
- `temperatures[2][0]`

Then write Python statements that display each value.

**Write your predicted answers in your workbook. Run the code to check them, then add a printscreen of your code and output to your workbook.**

## Task 2 — Cinema Seats

Create a 4 × 5 array using `"A"` for available seats and `"B"` for booked seats.

Your program should:

- display the seating plan one row at a time
- ask the user for a row and column
- validate both indexes
- book an available seat
- explain if the selected seat is already booked
- display the updated seating plan

**Run and test your program, then add a printscreen of your code and output to your workbook. Your output should demonstrate a seat being booked.**
