# Inheritance and Subclasses

!!! info "What You Need to Know"

    You must be able to describe, exemplify and implement superclasses, subclasses and inheritance.

## The Problem of Repeated Code

Suppose a program needs pupil and teacher objects. Both types of person have a name, so defining them independently repeats code:

```python
class Pupil:
    def __init__(self, name):
        self.name = name


class Teacher:
    def __init__(self, name):
        self.name = name
```

Inheritance allows shared properties and methods to be defined once in a **superclass**.

## The Main Idea

```text
Person superclass
├── property: name
└── method: display_name()
        ▲
        │ inherits
        │
Pupil subclass
└── property: year_group
```

The same relationship in Python is:

```python
class Person:

    def __init__(self, name):
        self.name = name

    def display_name(self):
        print(self.name)


class Pupil(Person):

    def __init__(self, name, year_group):
        super().__init__(name)
        self.year_group = year_group
```

| Conceptual view | Python |
|---|---|
| Superclass | `class Person:` |
| Subclass | `class Pupil(Person):` |
| Call superclass initialiser | `super().__init__(name)` |
| Subclass-only property | `self.year_group` |

## Step 1 — Define the Superclass

The superclass contains features shared by more than one type of object:

```python
class Person:

    def __init__(self, name):
        self.name = name

    def display_name(self):
        print(self.name)
```

## Step 2 — Define the Subclass

Write the superclass name in brackets after the subclass name:

```python
class Pupil(Person):
    ...
```

This means that `Pupil` inherits the properties and methods defined by `Person`.

## Step 3 — Call the Superclass Initialiser

```python
def __init__(self, name, year_group):
    super().__init__(name)
    self.year_group = year_group
```

`super().__init__(name)` sends `name` to the `Person` initialiser. That initialiser stores it in `self.name`.

The `Pupil` initialiser then adds the property needed only by pupils: `self.year_group`.

## Step 4 — Create a Subclass Object

```python
pupil1 = Pupil("Alice", 6)
```

The completed object contains both inherited and subclass properties:

```text
pupil1
├── name: Alice       ← inherited from Person
└── year_group: 6     ← defined by Pupil
```

## Step 5 — Use an Inherited Method

```python
pupil1.display_name()
```

`display_name()` is not written inside `Pupil`, but a pupil object can use it because it was inherited from `Person`.

## Adding Another Subclass

```python
class Teacher(Person):

    def __init__(self, name, subject):
        super().__init__(name)
        self.subject = subject
```

`Pupil` and `Teacher` both inherit `name` and `display_name()` while adding their own specialised properties.

```text
             Person
            /      \
       Pupil        Teacher
   year_group       subject
```

## Complete Working Example

```python title="Person, Pupil and Teacher" linenums="1"
class Person:

    def __init__(self, name):
        self.name = name

    def display_name(self):
        print("Name:", self.name)


class Pupil(Person):

    def __init__(self, name, year_group):
        super().__init__(name)
        self.year_group = year_group


class Teacher(Person):

    def __init__(self, name, subject):
        super().__init__(name)
        self.subject = subject


pupil1 = Pupil("Alice", 6)
teacher1 = Teacher("Mrs Smith", "Computing")

pupil1.display_name()
print("Year group:", pupil1.year_group)

teacher1.display_name()
print("Subject:", teacher1.subject)
```

## Common Mistakes

### Omitting the Superclass Name

```python
# Does not inherit from Person
class Pupil:
    ...

# Inherits from Person
class Pupil(Person):
    ...
```

### Forgetting `super().__init__()`

If the superclass initialiser is not called, its properties may not be created.

### Recreating an Inherited Property

Let the superclass initialise shared properties rather than duplicating the assignment in every subclass.
