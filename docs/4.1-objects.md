# Objects

## What is an Object?

An object is an instance of a class.

Objects are used to represent real-world entities within a program. Each object contains its own data and can perform its own actions.

For example:

* A pupil in a school system
* A customer in an online shop
* A car in a driving simulator
* A player in a game

Object-oriented programming (OOP) allows programs to model real-world situations by creating and using objects.

---

## Classes and Objects

A class acts as a blueprint for creating objects.

The class defines:

* Properties (attributes)
* Methods (behaviours)

An object is created from the class.

### Example

```python linenums="1"
class Pupil:

    def __init__(self, name, year_group):
        self.name = name
        self.year_group = year_group
```

The class defines what information every Pupil object should store.

---

## Instantiation

Instantiation is the process of creating an object from a class.

```python linenums="1"
pupil1 = Pupil("Alice", 6)
pupil2 = Pupil("Ben", 5)
```

Two separate objects have been created.

Although both objects were created from the same class, they store different data.

---

## Properties

Properties are variables stored within an object.

They hold information about the object.

```python linenums="1"
print(pupil1.name)
print(pupil1.year_group)
```

Output:

```text
Alice
6
```

Properties are accessed using dot notation.

---

## Methods

Methods are procedures that belong to an object.

They define actions that an object can perform.

```python linenums="1"
class Pupil:

    def __init__(self, name, year_group):
        self.name = name
        self.year_group = year_group

    def display_details(self):
        print(self.name)
        print(self.year_group)
```

Calling the method:

```python linenums="1"
pupil1.display_details()
```

Output:

```text
Alice
6
```

---

## Dot Notation

Dot notation is used to access properties and methods.

```python linenums="1"
pupil1.name

pupil1.display_details()
```

The dot separates the object name from the property or method being accessed.

---

## Multiple Objects

Many objects can be created from the same class.

```python linenums="1"
pupil1 = Pupil("Alice", 6)
pupil2 = Pupil("Ben", 5)
pupil3 = Pupil("Cara", 6)
```

Each object has its own copy of the properties.

Changing one object does not affect the others.

## Complete Working Example

```python linenums="1"
class Pupil:

    def __init__(self, name, year_group):
        self.name = name
        self.year_group = year_group

    def display_details(self):
        print("Name:", self.name)
        print("Year group:", self.year_group)


pupil1 = Pupil("Alice", 6)
pupil2 = Pupil("Ben", 5)

pupil1.display_details()
print()
pupil2.display_details()
```

Output:

```text
Name: Alice
Year group: 6

Name: Ben
Year group: 5
```

## Why Use Objects?

Objects help programmers to:

* Organise related data together
* Reuse code efficiently
* Model real-world entities
* Reduce duplication
* Create larger and more maintainable systems

Objects are used extensively in modern software development.

| Term | Meaning |
|------|---------|
| Class | Blueprint used to create objects |
| Object | Instance of a class |
| Property | Data stored within an object |
| Method | Action performed by an object |
| Instantiation | Creating an object from a class |
| Dot Notation | Used to access properties and methods |

---

## Summary

An object is an instance of a class.

Objects contain:

* Properties that store data
* Methods that perform actions

Objects allow programmers to represent and manipulate real-world entities within software systems.
