

# Arrays of Objects

## What is an Array of Objects?

An array of objects allows multiple objects created from the same class to be stored in a single array.

Each object in the array has its own set of properties and methods.

Arrays of objects are useful when a program needs to store and process large collections of similar objects.

Examples include:

* A school storing multiple pupils
* A garage storing multiple cars
* A library storing multiple books
* A game storing multiple enemies

---

## Creating a Class

Before creating an array of objects, a class must be defined.

```python linenums="1"
class Pupil:

    def __init__(self, name, year_group):
        self.name = name
        self.year_group = year_group
```

This class contains two properties:

* name
* year_group

---

## Creating Objects

Objects can be created from the class.

```python linenums="1"
pupil1 = Pupil("Alice", 6)
pupil2 = Pupil("Bob", 5)
pupil3 = Pupil("Charlie", 6)
```

Each object stores different data but has the same structure.

---

## Creating an Array of Objects

The objects can be stored inside an array.

```python linenums="1"
pupils = [
    Pupil("Alice", 6),
    Pupil("Bob", 5),
    Pupil("Charlie", 6)
]
```

The array now contains three Pupil objects.

---

## Accessing Objects in an Array

Individual objects can be accessed using an index.

```python linenums="1"
print(pupils[0].name)
```

Output:

```text
Alice
```

The first index identifies the object.

The property name is then accessed using dot notation.

---

## Accessing Multiple Properties

```python linenums="1"
print(pupils[1].name)
print(pupils[1].year_group)
```

Output:

```text
Bob
5
```

---

## Updating an Object

Properties can be changed after an object has been created.

```python linenums="1"
pupils[2].year_group = 7

print(pupils[2].year_group)
```

Output:

```text
7
```

---

## Looping Through an Array of Objects

A loop can be used to process every object in the array.

```python linenums="1"
for pupil in pupils:
    print(pupil.name)
```

Output:

```text
Alice
Bob
Charlie
```

---

## Using Methods in an Array of Objects

Objects often contain methods as well as properties.

```python linenums="1"
class Pupil:

    def __init__(self, name, year_group):
        self.name = name
        self.year_group = year_group

    def display(self):
        print(self.name, self.year_group)
```

The method can be called for every object in the array.

```python linenums="1"
for pupil in pupils:
    pupil.display()
```

---

## Example: Array of Car Objects

```python linenums="1"
class Car:

    def __init__(self, make, colour):
        self.make = make
        self.colour = colour

cars = [
    Car("Ford", "Blue"),
    Car("BMW", "Black"),
    Car("Toyota", "White")
]

for car in cars:
    print(car.make)
```

Output:

```text
Ford
BMW
Toyota
```

---

## Why Use Arrays of Objects?

Arrays of objects allow programs to:

* Store large numbers of similar objects
* Process objects efficiently using loops
* Organise related data together
* Simplify complex programs

They are commonly used in games, databases, simulations and management systems.

---

## Summary

| Term | Description |
|------|-------------|
| Class | A blueprint used to create objects |
| Object | An instance of a class |
| Array of Objects | A collection of objects stored in an array |
| Property | Data stored within an object |
| Method | A procedure belonging to an object |
| Dot Notation | Used to access properties and methods |
