# Creating an Array of Objects

An array of objects allows a program to store and manage multiple objects using a single collection.

In our library system, each `Book` object represents a physical copy of a book, with its own title, copy number and loan status.

Python uses lists to store references to these objects. Objects can be created separately and then added to a list, or created directly inside the list.

This lesson explains how to create an array of `Book` objects and organise them using list indices.

## Step 1 – Define the Book Class

Before creating objects, we need to define the class they will be created from.

The following program uses the same `Book` class introduced in the Polymorphism chapter.

```python
class Book:
    def __init__(self, title, copy_number):
        self.title = title
        self.copy_number = copy_number
        self._on_loan = False

    def get_loan_status(self):
        return self._on_loan

    def set_loan_status(self, status):
        if type(status) is bool:
            self._on_loan = status

    def get_description(self):
        return self.title + " #" + str(self.copy_number)
```

The class defines the properties and methods available to every `Book` object.

The `__init__()` method sets the initial property values when a new object is created.

The `_on_loan` property is initially set to `False` because a newly created book is not on loan.

We can now create objects from this class.

## Step 2 – Create Separate Objects

First, create three `Book` objects using separate variables.

Add the following code below the class definition.

```python
book1 = Book("The Hobbit", 101)
book2 = Book("1984", 102)
book3 = Book("Coraline", 103)
```

Each call to `Book(...)` creates a separate object.

| Variable | Title | Copy number |
|---|---|---|
| `book1` | The Hobbit | 101 |
| `book2` | 1984 | 102 |
| `book3` | Coraline | 103 |

Each variable refers to a different object.

Although all three objects are created from the same class, they have their own property values.

## Step 3 – Create the Array

We can now store references to these objects together in a Python list.

Add:

```python
books = [book1, book2, book3]
```

The list is called `books`.

It contains three elements, each referring to one of the objects we created.

The objects are not copied when their references are placed in the list.

We can use `len()` to find the number of elements.

```python
print(len(books))
```

Output:

```text
3
```

The array contains three `Book` objects.
