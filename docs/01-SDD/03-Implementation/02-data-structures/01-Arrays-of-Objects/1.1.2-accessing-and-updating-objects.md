# Accessing and Updating Objects

An array index allows a program to select a particular object from a collection.

Once an object has been selected, **dot notation** can be used to access its properties or call its methods.

In our library system, this allows us to retrieve information about individual books and update their loan status.

## Accessing an Object

The `books` array contains three objects:

| Index | Title | Copy number |
|---|---|---|
| `0` | The Hobbit | 101 |
| `1` | 1984 | 102 |
| `2` | Coraline | 103 |

An index identifies the position of an object in the array.

For example:

```python
books[0]
```

selects the first `Book` object.

Similarly:

```python
books[2]
```

selects the third object.

Python starts counting array indices at `0`, so an array containing three elements has valid indices of `0`, `1` and `2`.

## Reading an Object's Properties

We can combine an array index with dot notation to access a property belonging to the selected object.

Open your program from **Creating an Array of Objects**.

Keep the `Book` class and the array containing three books. Replace the final `print()` statement with:

```python
print(books[0].title)
print(books[1].copy_number)
```

Output:

```text
The Hobbit
102
```

The expression:

```python
books[0].title
```

has three parts:

| Part | Purpose |
|---|---|
| `books` | Identifies the array |
| `[0]` | Selects the first object |
| `.title` | Accesses the object's title property |

The same approach can be used to access other public properties.

For example:

```python
print(books[2].title)
print(books[2].copy_number)
```

Output:

```text
Coraline
103
```

Both instructions access properties belonging to the object at index `2`.

## Calling an Object's Method

Objects also have methods defined by their class.

To call a method, we use dot notation followed by the method name and brackets.

For example:

```python
print(books[2].get_description())
```

Output:

```text
Coraline #103
```

The expression:

```python
books[2].get_description()
```

first selects the object at index `2`.

Python then calls its `get_description()` method.

The method uses the selected object's title and copy number to return a description.

**Remember:** Accessing a property retrieves a stored value. Calling a method executes instructions defined by the object's class.

## Updating an Object's Loan Status

The library needs to record when a book is borrowed.

Our `Book` class stores the loan status in the `_on_loan` property.

This property is managed using two methods:

- `get_loan_status()` returns the current loan status.
- `set_loan_status()` changes the loan status.

Suppose the book at index `1`, *1984*, is borrowed.

We can update its loan status using:

```python
books[1].set_loan_status(True)
```

This selects the second object and calls its setter method.

We can check the result using:

```python
print("Copy 102:", books[1].get_loan_status())
```

Output:

```text
Copy 102: True
```

The loan status is now `True`, indicating that the book is on loan.

Using the setter method also reinforces **encapsulation**, because the class controls how its loan status is changed.

## Objects Maintain Their Own State

Each element in our array refers to a separate `Book` object.

Changing one object's loan status does not automatically change the others.

For example:

```python
books[1].set_loan_status(True)

print("Copy 102:", books[1].get_loan_status())
print("Copy 101:", books[0].get_loan_status())
```

Output:

```text
Copy 102: True
Copy 101: False
```

Copy `102` is on loan, but copy `101` remains available.

Both objects belong to the same class, but they maintain their own property values.

## Common Mistakes

### Forgetting the Array Index

The array itself is not a `Book` object.

```python
# Incorrect
print(books.title)

# Correct
print(books[0].title)
```

We must select an object before accessing its properties.

### Using an Invalid Index

Our array contains three objects.

```python
# Incorrect
print(books[3].title)
```

This produces an `IndexError` because there is no element at index `3`.

The highest valid index is `2`.

### Forgetting the Method Brackets

```python
# Incorrect
print(books[0].get_description)

# Correct
print(books[0].get_description())
```

The brackets are required to call the method.

!!! info "Key Points"
    - An array index selects an individual object.
    - Python list indices begin at `0`.
    - Dot notation allows us to access an object's public properties.
    - Dot notation also allows us to call an object's methods.
    - Getter methods return information about an object's state.
    - Setter methods can update an object's state.
    - Each separately created object maintains its own property values.
    - Accessing an invalid index produces an `IndexError`.
