# Arrays of Objects

## One array, three separate objects

An **array of objects** is a collection in which each element holds a reference to an object. In Python, we use a **list** to implement it. A list can grow as the library adds more books.

Each position in the list has a number called an **index**. The diagram shows three positions in a list called `books`. The arrows show which object each position refers to.

For example, the element at index `0` refers to *The Hobbit*, copy 101. The book's copy number identifies it in the library. The index tells the program where its reference sits in the list.

## Arrays of Records vs. Arrays of Objects

An **array of records** contains records, with each record storing a collection of related fields.

An **array of objects** contains references to objects created from a class. Each object has its own properties and can use the methods defined by its class.

For example, a `Book` object stores properties such as `title`, `copy_number` and `_on_loan`. It can also use methods such as `get_description()` and `get_loan_status()`.

| Array of Records | Array of Objects |
|---|---|
| Each element contains a record | Each element refers to an object |
| Records contain related fields | Objects have related properties and methods |
| Used to organise and process data | Used to organise data and associated behaviour |

The important difference is that **objects combine data with the methods that operate on that data**.
