# Processing Arrays of Objects

**Traversing** a list means visiting its elements one at a time. A loop can display every entry in the catalogue or use each book's loan status to decide which entries to display.

## Visiting every book

Using the original three-book list, add this loop below your list and run it. On each iteration, `book` refers to the next object.

```python
for book in books:
    print(book.get_description())
```

```text
The Hobbit #101
1984 #102
Coraline #103
```

If you need each position as well as its object, loop over the indices. `len(books)` gives the number of entries and `range(len(books))` gives the indices from zero up to the last valid position.

```python
for index in range(len(books)):
    print(index, books[index].get_description())
```

```text
0 The Hobbit #101
1 1984 #102
2 Coraline #103
```

## Adding a book and displaying loans

`append()` adds an entry at the end of a list. Pass it a new `Book` object to add a copy to the catalogue. The complete program below adds copy 104, displays the catalogue, then uses an `if` statement to display only the books on loan.

```python
class Book:
    def __init__(self, title, copy_number):
        self.title = title
        self.copy_number = copy_number
        self._on_loan = False

    def get_loan_status(self):
        return self._on_loan

    def set_loan_status(self, status):
        if type(status) is bool:
            self._on_loan = status

    def get_description(self):
        return self.title + " #" + str(self.copy_number)


books = [
    Book("The Hobbit", 101),
    Book("1984", 102),
    Book("Coraline", 103)
]

books[1].set_loan_status(True)
books.append(Book("Noughts & Crosses", 104))

print("Catalogue")
for book in books:
    print(book.get_description())

print("On loan")
for book in books:
    if book.get_loan_status():
        print(book.get_description())
```

```text
Catalogue
The Hobbit #101
1984 #102
Coraline #103
Noughts & Crosses #104
On loan
1984 #102
```

Create the list before the loops so both loops work with the same catalogue. In the second loop, the description is displayed only when the getter returns `True`.

Use a direct loop to visit the objects, or an index loop when you need their positions. Append new objects and use their current values to decide which entries to process.
