# Arrays of Objects and Polymorphism

An `AudioBook` is a subclass of `Book`. It has a duration and overrides `get_description()` to include that duration. Because both classes provide this method, a list can contain both kinds of object and a single loop can display their descriptions.

## One loop, two descriptions

Keep the `Book` definition from the previous lesson. Add the `AudioBook` definition below it and replace the code after the class definitions with this list and loop.

```python
class AudioBook(Book):
    def __init__(self, title, copy_number, duration):
        super().__init__(title, copy_number)
        self.duration = duration

    def get_description(self):
        return self.title + " #" + str(self.copy_number) + " - " + str(self.duration) + " minutes"


books = [
    Book("The Hobbit", 101),
    AudioBook("The Hobbit", 102, 680),
    Book("Coraline", 103)
]

for book in books:
    print(book.get_description())
```

```text
The Hobbit #101
The Hobbit #102 - 680 minutes
Coraline #103
```

The loop makes the same call for each item. Python uses `Book.get_description()` for copies 101 and 103 and the overridden `AudioBook.get_description()` for copy 102. This is **polymorphism**. The loop needs only the shared method name.

Each object supplies the version of the method appropriate to its class. The list and the loop work with both kinds of book.
