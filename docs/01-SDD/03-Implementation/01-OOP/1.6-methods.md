# Methods

Previously, we learned how to define a class and create objects with their own properties.

Properties store information about an object. However, objects also need to carry out actions.

A **method** is a function defined inside a class. Methods define actions that objects can perform, such as returning information or changing property values.

## Defining a Method

Our library system needs to produce a label showing a book's title and copy number.

We can add a method called `label()` to the `Book` class.

```python
class Book:
    def __init__(self, title, copy_number):
        self.title = title
        self.copy_number = copy_number
        self.on_loan = False

    def label(self):
        return self.title + " #" + str(self.copy_number)
```

The `label()` method is defined inside the `Book` class using the `def` keyword.

Notice that the method includes `self` as a parameter. This allows it to access the properties of the particular object using the method.

Inside the method:

- `self.title` accesses the book's title.
- `self.copy_number` accesses its copy number.
- `str()` converts the copy number into a string so it can be joined with the title.
- `return` sends the completed label back to the code that called the method.

The method does not change any properties. It uses the existing values to produce a result.

## Calling a Method

Once an object has been created, we can call one of its methods using **dot notation**.

Add the following code below the class definition:

```python
book = Book("The Hobbit", 101)

print(book.label())
```

Output:

```text
The Hobbit #101
```

The expression `book.label()` tells Python to run the `label()` method belonging to the object referenced by `book`.

Python automatically passes that object as `self`, allowing the method to access its properties.

The method returns the string `"The Hobbit #101"`, which `print()` displays on the screen.

Notice the difference between accessing a property and calling a method:

- `book.title` accesses a property.
- `book.label()` calls a method.

The brackets `()` indicate that the method is being called.

## Methods That Change Properties

Methods can also change the values stored in an object's properties.

For example, when somebody borrows a book, the library system needs to update its loan status.

We can add a method called `borrow()` to the `Book` class.

```python
def borrow(self):
    self.on_loan = True
```

This method changes the `on_loan` property of the object to `True`.

Unlike `label()`, the `borrow()` method does not return a result. Its purpose is to change the object's state.

To use it, we call the method on a book object:

```python
book.borrow()

print(book.on_loan)
```

Output:

```text
True
```

The method changes the loan status of the object referenced by `book`.

Other book objects are unaffected because each object stores its own property values.

## Putting It All Together

The following program combines both methods in the `Book` class.

```python
class Book:
    def __init__(self, title, copy_number):
        self.title = title
        self.copy_number = copy_number
        self.on_loan = False

    def label(self):
        return self.title + " #" + str(self.copy_number)

    def borrow(self):
        self.on_loan = True


book = Book("The Hobbit", 101)

print(book.label())
print(book.on_loan)

book.borrow()

print(book.on_loan)
```

Output:

```text
The Hobbit #101
False
True
```

The program creates a book object and displays its label and initial loan status.

It then calls `borrow()`, which changes the book's loan status to `True`.

The final `print()` confirms that the property's value has changed.

!!! info "Key Points"
    - A **method** is a function defined inside a class.
    - Methods describe actions that objects can perform.
    - Methods can access properties, change values or return results.
    - The `self` parameter refers to the object using the method.
    - Dot notation and brackets are used to call methods, such as `book.borrow()`.
    - Methods appear in the bottom compartment of a UML class diagram.
