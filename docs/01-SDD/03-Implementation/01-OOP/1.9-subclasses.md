# Subclasses

In the previous chapter, we learned that inheritance allows a subclass to reuse properties and methods from a superclass.

A **subclass** is a specialised class that inherits from another class. It can also define additional properties and methods of its own.

This allows programmers to reuse existing code while adding features needed by a particular type of object.

## Extending a Class

Our library system uses the `Book` class to represent books.

We have also introduced an `AudioBook` subclass, which inherits the properties and methods of `Book`.

An audiobook needs the same information as an ordinary book, including its title, copy number and loan status.

However, it also needs to store its duration.

We can extend `AudioBook` to include this additional property without repeating the code already defined in `Book`.

## Adding Properties to a Subclass

The following program builds on the `Book` class from the previous chapter.

```python
class Book:
    def __init__(self, title, copy_number):
        self.title = title
        self.copy_number = copy_number
        self._on_loan = False

    def get_loan_status(self):
        return self._on_loan

    def set_loan_status(self, status):
        if type(status) is bool:
            self._on_loan = status


class AudioBook(Book):
    def __init__(self, title, copy_number, duration):
        super().__init__(title, copy_number)
        self.duration = duration
```

The `AudioBook` class now has its own `__init__()` method.

This allows it to receive an additional value for `duration`.

The line:

```python
super().__init__(title, copy_number)
```

calls the superclass initialiser.

This sets up the properties inherited from `Book`, including `title`, `copy_number` and `_on_loan`.

The next line:

```python
self.duration = duration
```

stores the additional property belonging to the audiobook.

The subclass does not need to repeat the instructions that initialise the shared properties.

## Creating an Audiobook Object

We can now create an audiobook with its own duration.

Add the following code below the class definitions.

```python
audiobook = AudioBook("The Hobbit", 102, 680)

print(audiobook.title)
print(audiobook.duration)
print(audiobook.get_loan_status())
```

Output:

```text
The Hobbit
680
False
```

The audiobook stores the title and copy number inherited from `Book`, along with its own `duration` property.

In this example, the duration is measured in minutes.

The `get_loan_status()` method is inherited from `Book`, so it can be called without being defined again in `AudioBook`.

## Adding Methods to a Subclass

A subclass can also define methods that are not available in its superclass.

For example, we could add a method to `AudioBook` that returns its duration.

```python
def get_duration(self):
    return self.duration
```

This method belongs inside the `AudioBook` class and is not defined in `Book`.

It can be called using:

```python
print(audiobook.get_duration())
```

Output:

```text
680
```

To run this example, add `get_duration()` to the `AudioBook` class before creating the object.

This demonstrates that a subclass can inherit existing methods and introduce additional methods of its own.

!!! info "Key Points"
    - A **subclass** is a specialised class that inherits from a superclass.
    - A subclass can define additional properties and methods.
    - `super().__init__()` allows the subclass to use the superclass initialiser.
    - Inherited properties and methods do not need to be defined again.
    - A subclass can extend the functionality provided by its superclass.
    - UML inheritance arrows point towards the superclass.
