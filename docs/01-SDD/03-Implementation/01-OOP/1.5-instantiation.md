# Instantiation

In the previous chapter, we learned that a class defines the structure shared by its objects.

However, defining a class does not automatically create any objects.

**Instantiation** is the process of creating an object from a class.

Each object created from a class is called an **instance** of that class.

## Creating an Object

The library uses a class called `Book` to represent its books.

We can create an object from this class by writing the class name followed by brackets.

```python
book = Book("The Hobbit", 101)
```

The expression `Book("The Hobbit", 101)` creates a new book object.

The values `"The Hobbit"` and `101` provide the information needed to set up the object.

The variable `book` stores a **reference** to the newly created object. This allows the program to access the object later.

## Initialising an Object

When an object is created, its properties need starting values.

Python uses a special method called `__init__` to initialise an object.

```python
class Book:
    def __init__(self, title, copy_number):
        self.title = title
        self.copy_number = copy_number
        self.on_loan = False
```

The `__init__` method runs automatically when a new `Book` object is created.

Let's examine its parts.

- **`__init__`** is the special method used to set the object's starting values.
- **`self`** refers to the particular object being initialised.
- **`title` and `copy_number`** are parameters that receive values when an object is created.
- **`self.title = title`** stores the supplied title in the object's `title` property.
- **`self.copy_number = copy_number`** stores the supplied copy number.
- **`self.on_loan = False`** gives every new book a starting loan status of `False`.

Python automatically supplies `self`, so we only need to provide the title and copy number when creating a book.

## Creating Two Objects

We can use the same class to create more than one object.

```python
book1 = Book("The Hobbit", 101)
book2 = Book("The Hobbit", 102)
```

Each call to `Book()` creates a separate object.

Both objects have the same properties, but they can store different values.

The diagram below shows the two objects after they have been created.

| Book object 1 | Book object 2 |
|---|---|
| `title = "The Hobbit"` | `title = "The Hobbit"` |
| `copy_number = 101` | `copy_number = 102` |
| `on_loan = False` | `on_loan = False` |

The variables `book1` and `book2` refer to different objects.

Changing a property of one object does not automatically change the other.

## Accessing an Object's Properties

Once an object has been created, we can use its reference to access its properties.

```python
book1.on_loan = True

print(book1.on_loan)
print(book2.on_loan)
```

The output is:

```text
True
False
```

Only `book1` has been changed.

Although both objects were created from the same class, they each store their own property values.

!!! info "Key Points"
    - **Instantiation** means creating an object from a class.
    - An **instance** is an individual object created from a class.
    - Python creates an object when the class is called, such as `Book("The Hobbit", 101)`.
    - The `__init__` method sets the object's starting values.
    - `self` refers to the object being initialised.
    - A variable such as `book1` holds a reference to an object.
    - Each new class call creates a separate object.
