# Inheritance

In the previous chapters, we learned how classes define properties and methods, and how encapsulation can control access to an object's data.

Sometimes, different types of objects need many of the same properties and methods.

**Inheritance** allows a class to reuse the properties and methods defined in another class.

This reduces repeated code and makes programs easier to maintain.

## Why Is Inheritance Useful?

Our library system uses a `Book` class to represent books.

The library also lends audiobooks. An audiobook needs much of the same information as an ordinary book, including its title, copy number and loan status.

However, an audiobook also needs to store its duration.

Rather than repeating the shared properties and methods in a separate class, we can use inheritance.

The `Book` class is the **superclass** (parent class).

The `AudioBook` class is the **subclass** (child class).

The subclass inherits properties and methods from its superclass.

## Inheritance in Python

Python uses the superclass name in brackets when defining a subclass.

The following program defines a `Book` class and an `AudioBook` subclass.

```python
class Book:
    def __init__(self, title, copy_number):
        self.title = title
        self.copy_number = copy_number
        self._on_loan = False

    def get_loan_status(self):
        return self._on_loan

    def set_loan_status(self, status):
        if type(status) is bool:
            self._on_loan = status


class AudioBook(Book):
    pass
```

The line:

```python
class AudioBook(Book):
```

defines `AudioBook` as a subclass of `Book`.

The name `Book` in brackets tells Python which class to inherit from.

The `pass` statement means that we have not added any new code to the subclass yet.

Even though `AudioBook` does not define its own methods, it can use the methods inherited from `Book`.

## Using Inherited Properties and Methods

Add the following code below the class definitions.

```python
audiobook = AudioBook("The Hobbit", 102)

print(audiobook.title)
print(audiobook.get_loan_status())
```

Output:

```text
The Hobbit
False
```

The `AudioBook` class inherits the `__init__()` method from `Book`.

When the audiobook is created, the inherited initialiser sets its starting property values.

The `get_loan_status()` method is also inherited from `Book`.

This means we can call the method on an audiobook object even though it has not been defined again in `AudioBook`.

## Changing an Inherited Property

An audiobook can also use the inherited setter method to change its loan status.

```python
audiobook.set_loan_status(True)

print(audiobook.get_loan_status())
```

Output:

```text
True
```

The setter method changes the audiobook's loan status to `True`.

The getter method then returns the updated value.

Both methods are inherited from `Book`, so we do not need to write them again in `AudioBook`.

## Benefits of Inheritance

Inheritance offers several advantages.

- **Code reuse:** Shared properties and methods can be defined once in the superclass.
- **Maintainability:** Changes to inherited methods can also benefit subclasses.
- **Organisation:** Related classes can be arranged into a clear hierarchy.

For example, if the library changes how loan status is managed, the shared methods can be updated in `Book` rather than separately in every subclass that inherits them.

!!! info "Key Points"
    - **Inheritance** allows a subclass to reuse properties and methods from a superclass.
    - A **superclass** is the class being inherited from.
    - A **subclass** is the class that inherits.
    - UML represents inheritance using a solid line with a hollow triangular arrowhead pointing towards the superclass.
    - Python uses the superclass name in brackets when defining a subclass.
    - A subclass can use inherited properties and methods without defining them again.
    - Inheritance reduces repeated code and improves maintainability.
