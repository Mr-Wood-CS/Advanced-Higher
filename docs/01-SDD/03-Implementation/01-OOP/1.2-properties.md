# Properties

A property stores one piece of information about an object.

==Every property has a name and a value.== 

The name identifies the information being stored, while the value is the information the object currently holds.

## Object Diagrams

An object diagram is a visual way of showing an object and the information stored about it.

The library book from the previous chapter provides an example of how properties store information about an object.

<figure class="object-diagram" aria-labelledby="library-object">

          <div>On loan: Yes</div>
        </div>
      </div>
    </div>
  </div>
</figure>

The diagram has two compartments. The top identifies the object being represented. The lower compartment shows its properties and their current values.

In this example:

- **title stores** "The Hobbit", the name of the book.
- **copy_number** stores 101, the number used to identify this physical copy.
- The **on_loan** property stores a Boolean value. True means the book is currently borrowed, while False means it is available.
