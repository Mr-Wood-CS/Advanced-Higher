# Project: School Library Manager

You are going to create an object-oriented program for a school library.

The library lends books and DVDs. All library items have some features in common, but each item type also stores different information.

## What the Program Should Do

The finished program should:

- store a unique ID and title for every library item
- record privately whether an item is available
- use methods to borrow and return an item
- store an author for each book
- store a duration in minutes for each DVD
- display appropriate details for books and DVDs
- store all item objects in one array
- process the different objects using one loop
- allow the user to enter an item ID to borrow
- explain when an item ID is invalid or the selected item is unavailable
