  Read the underlined heading `copy1 : Book` from left to right. **`copy1`** is the object reference, a name the program can use to refer to this particular object. **`Book`** is the class. A **class** defines what objects of that kind can store and do. We say that `copy1` refers to an **instance** of `Book`, meaning one individual object made from that class.

In the lower compartment, each line pairs a property name on the left of the equals sign with its current value on the right. For example, `copy_number = 101` tells you that the property named `copy_number` currently holds the value `101`.

The `+` means the property is public, so other code can access it. A type tells you what kind of value belongs in a property. For example, `on_loan` can hold `True` or `False`. Once the program creates a book object, that object has a current value for each property.

Use dot notation to read a property. In `book.on_loan`, `book` refers to the object and `on_loan` selects its current loan status. An assignment such as `book.on_loan = True` changes that object's status.
