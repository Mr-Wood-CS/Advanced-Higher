# Encapsulation

## What is Encapsulation?

Encapsulation is an object-oriented programming (OOP) principle that combines data and the methods that operate on that data into a single unit called an object.

Encapsulation also helps protect data by controlling how it can be accessed and modified.

This helps to maintain the integrity of the data stored within an object.

---

## Why is Encapsulation Important?

Encapsulation helps programmers to:

* Protect data from accidental modification
* Control how data is accessed
* Improve program security
* Reduce errors
* Make programs easier to maintain

By controlling access to data, objects can ensure that only valid values are stored.

---

## Encapsulation in a Class

A class contains:

* Properties (data)
* Methods (behaviour)

These are grouped together inside the object.

```python linenums="1"
class Pupil:

    def __init__(self, name, year_group):
        self.name = name
        self.year_group = year_group
        self.attendance = 0

    def set_attendance(self, attendance):
        self.attendance = attendance
```

The data and methods are encapsulated within the Pupil object.

---

## Restricting Access to Data

In many object-oriented languages, properties can be made private so that they cannot be accessed directly from outside the class.

This ensures that data can only be changed using approved methods.

### Example

```python linenums="1"
class Pupil:

    def __init__(self, name, year_group):
        self.name = name
        self.year_group = year_group
        self.__attendance = 0
```

The double underscore indicates that attendance should be treated as a private property.

---

## Using Methods to Access Data

Instead of changing data directly, methods can be used.

```python linenums="1"
class Pupil:

    def __init__(self, name, year_group):
        self.name = name
        self.year_group = year_group
        self.__attendance = 0

    def set_attendance(self, attendance):
        self.__attendance = attendance

    def get_attendance(self):
        return self.__attendance
```

Creating an object:

```python linenums="1"
pupil1 = Pupil("Alice", 6)

pupil1.set_attendance(95)

print(pupil1.get_attendance())
```

Output:

```text
95
```

## Preventing Invalid Data

Encapsulation allows validation to be built into methods.

```python linenums="1"
class Pupil:

    def __init__(self, name, year_group):
        self.name = name
        self.year_group = year_group
        self.__attendance = 0

    def set_attendance(self, attendance):
        if 0 <= attendance <= 100:
            self.__attendance = attendance
```

The validation ensures that attendance cannot be less than 0 or greater than 100.

Without encapsulation, invalid values could be stored accidentally.

## Encapsulation and Objects

Encapsulation means that an object is responsible for managing its own data.

Rather than allowing external code to change properties directly, methods provide controlled access to the data.

This helps keep objects reliable and self-contained.

---

## Complete Working Example

```python linenums="1"
class Person:

    def __init__(self, name):
        self.name = name


class Pupil(Person):

    def __init__(self, name, year_group):
        super().__init__(name)
        self.year_group = year_group
        self.__attendance = 0

    def set_attendance(self, attendance):
        if 0 <= attendance <= 100:
            self.__attendance = attendance
        else:
            print("Attendance must be between 0 and 100")

    def get_attendance(self):
        return self.__attendance

    def display_details(self):
        print("Pupil:", self.name)
        print("Year group:", self.year_group)
        print("Attendance:", str(self.__attendance) + "%")


pupil1 = Pupil("Alice", 6)

pupil1.set_attendance(95)
pupil1.display_details()

pupil1.set_attendance(120)
print("Stored attendance:", str(pupil1.get_attendance()) + "%")
```

Output:

```text
Pupil: Alice
Year group: 6
Attendance: 95%
Attendance must be between 0 and 100
Stored attendance: 95%
```

## Summary

Encapsulation is the process of combining data and methods within an object while controlling access to that data.

Encapsulation helps:

* Protect data
* Validate input
* Improve reliability
* Improve maintainability

It is a fundamental principle of object-oriented programming and is commonly used alongside classes, objects and inheritance.
