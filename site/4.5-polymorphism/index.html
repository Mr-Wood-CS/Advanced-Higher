Polymorphism

What is Polymorphism?

Polymorphism is an object-oriented programming (OOP) concept that allows the same method name to behave differently depending on the object that is using it.

The word polymorphism means "many forms".

This allows different classes to respond to the same method call in different ways.

Why is Polymorphism Useful?

Polymorphism helps programmers to:

  • Reuse code
  • Reduce duplication
  • Write more flexible programs
  • Make systems easier to extend
  • Work with groups of related objects

Polymorphism Through Inheritance

Polymorphism is commonly used alongside inheritance.

Different subclasses can provide their own version of the same method.

Superclass

```python linenums="1" class Person:

def display_details(self):
    print("Person details")


### Subclasses

```python linenums="1"
class Pupil(Person):

    def display_details(self):
        print("Pupil details")

class Teacher(Person):

    def display_details(self):
        print("Teacher details")

Both subclasses contain a method called display_details(), but each behaves differently.

Calling the Same Method

```python linenums="1" pupil1 = Pupil() teacher1 = Teacher()

pupil1.display_details() teacher1.display_details()


Output:

```text
Pupil details
Teacher details

The same method name is used, but different behaviour occurs depending on the object.

This is polymorphism.

Using Polymorphism with Arrays of Objects

One of the biggest advantages of polymorphism is that different objects can be processed using the same code.

```python linenums="1" people = [Pupil(), Teacher()]

for person in people: person.display_details()


Output:

```text
Pupil details
Teacher details

The program does not need to know whether the object is a Pupil or a Teacher.

It simply calls the display_details() method.

Superclass

def display_details(self):
    pass


### Subclasses

```python linenums="1"
class Pupil(Person):

    def display_details(self):
        print("Pupil details")

class Teacher(Person):

    def display_details(self):
        print("Teacher details")

Using Polymorphism

```python linenums="1" people = [Pupil(), Teacher()]

for person in people: person.display_details()


Output:

```text
Pupil details
Teacher details

Although the same method is called, each object performs its own version of the action.

Relationship Between Inheritance and Polymorphism

Inheritance creates the relationship between classes.

Polymorphism allows those related classes to respond differently to the same method call.

          Person
             ▲
             |
      ----------------
      |              |
    Pupil         Teacher

Both subclasses implement:

display_details()

Inheritance provides the structure.

Polymorphism provides the different behaviour.

Advantages of Polymorphism

Advantage Explanation
Reusability The same code can work with different objects
Flexibility New subclasses can be added easily
Maintainability Less duplicated code is required
Extensibility Systems can be expanded without major changes
Simplicity One method call can work with many object types

Common Mistakes

Mistake Explanation
Confusing inheritance with polymorphism Inheritance creates the relationship; polymorphism creates different behaviour
Creating different method names Polymorphism requires the same method name
Forgetting to override the method Subclasses should provide their own implementation
Not using a common superclass Polymorphism is usually based on inheritance

Summary

Polymorphism allows different objects to respond differently to the same method call.

It is commonly used with inheritance and method overriding.

Benefits include:

  • Greater flexibility
  • Better code reuse
  • Easier maintenance
  • More scalable software systems

Polymorphism is one of the core principles of object-oriented programming alongside classes, objects, inheritance and encapsulation.
