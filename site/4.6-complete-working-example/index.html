Complete Working Example

This program combines the object-oriented programming concepts from this section:

  • Objects
  • Inheritance
  • Encapsulation
  • Polymorphism

The example uses a school register system with a superclass called Person and two subclasses called Pupil and Teacher.

Program

```python linenums="1"

Person is the superclass.

It stores the data and methods shared by pupils and teachers.

class Person:

def __init__(self, name):
    # Each person object stores its own name.
    self.name = name

def display_details(self):
    print("Name:", self.name)

Pupil is a subclass of Person.

It inherits the name property from Person.

class Pupil(Person):

def __init__(self, name, year_group, attendance):
    # Call the constructor from the superclass.
    super().__init__(name)

    # Store data that only pupil objects need.
    self.year_group = year_group

    # The double underscore makes attendance private.
    self.__attendance = 0

    # Use the method so the attendance value can be validated.
    self.set_attendance(attendance)

def set_attendance(self, attendance):
    # Only store attendance if it is a valid percentage.
    if 0 <= attendance <= 100:
        self.__attendance = attendance
    else:
        print("Attendance must be between 0 and 100")

def get_attendance(self):
    # Return the private attendance value.
    return self.__attendance

def display_details(self):
    # This method overrides display_details() from Person.
    print("Pupil:", self.name)
    print("Year group:", self.year_group)
    print("Attendance:", str(self.__attendance) + "%")

Teacher is another subclass of Person.

class Teacher(Person):

def __init__(self, name, subject):
    # Call the constructor from the superclass.
    super().__init__(name)

    # Store data that only teacher objects need.
    self.subject = subject

def display_details(self):
    # This method also overrides display_details() from Person.
    print("Teacher:", self.name)
    print("Subject:", self.subject)

Create a list containing different types of objects.

people = [ Pupil("Alice", 6, 95), Teacher("Mrs Smith", "Computing"), Pupil("Ben", 5, 88) ]

The same method call works for both Pupil and Teacher objects.

for person in people: person.display_details() print()

```text

Teacher: Mrs Smith
Subject: Computing

Pupil: Ben

How the Program Uses OOP

Concept How it is used
Object Each pupil and teacher is created as an object
Class Person, Pupil and Teacher define the structure of the objects
Inheritance Pupil and Teacher inherit from Person
Encapsulation The Pupil class stores attendance as a private property
Polymorphism The same display_details() method works differently for pupils and teachers

Summary

This complete example shows how object-oriented programming can be used to model a real-world system.

The program stores related data inside objects and allows different object types to respond to the same method call in their own way.
