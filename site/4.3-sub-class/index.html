Subclasses and Inheritance

What is a Subclass?

A subclass is a class that inherits properties and methods from another class.

The class being inherited from is called the superclass (or parent class).

Inheritance allows programmers to reuse existing code and create specialised versions of existing classes.

Why Use Inheritance?

Inheritance helps to:

  • Reduce code duplication
  • Improve code reuse
  • Create logical relationships between classes
  • Make programs easier to maintain
  • Extend existing classes with additional features

Superclass and Subclass

Consider a school register program.

All people in the register have a name.

Instead of writing the same code multiple times, a superclass can be created.

Superclass

```python linenums="1" class Person:

def __init__(self, name):
    self.name = name


---

### Subclass

```python linenums="1"
class Pupil(Person):

    def __init__(self, name, year_group):
        super().__init__(name)
        self.year_group = year_group

The Pupil class inherits the name property from Person.

It also introduces a new property called year_group.

Creating Objects from a Subclass

```python linenums="1" pupil1 = Pupil("Alice", 6)

print(pupil1.name) print(pupil1.year_group)


Output:

```text
Alice
6

The object has access to:

  • Inherited properties
  • Its own properties

Inheriting Methods

Subclasses inherit methods as well as properties.

```python linenums="1" class Person:

def __init__(self, name):
    self.name = name

def display_name(self):
    print(self.name)


```python linenums="1"
class Pupil(Person):
    pass

```python linenums="1" pupil1 = Pupil("Alice") pupil1.display_name()


Output:

```text
Alice

Even though the method is not written inside the subclass, it is inherited from the superclass.

Adding New Properties

A subclass can introduce additional properties.

```python linenums="1" class Pupil(Person):

def __init__(self, name, year_group):
    super().__init__(name)
    self.year_group = year_group


The subclass now contains:

* Inherited features from Person
* New features specific to Pupil

---

## Adding New Methods

A subclass can introduce additional methods.

```python linenums="1"
class Pupil(Person):

    def __init__(self, name, year_group):
        super().__init__(name)
        self.year_group = year_group

    def display_year_group(self):
        print(self.year_group)

Overriding Methods

A subclass can replace an inherited method with its own version.

```python linenums="1" class Person:

def display_details(self):
    print("Name:", self.name)


```python linenums="1"
class Teacher(Person):

    def display_details(self):
        print("Teacher:", self.name)

```python linenums="1" teacher1 = Teacher("Mrs Smith") teacher1.display_details()


Output:

```text
Teacher: Mrs Smith

This is known as method overriding.

UML Representation

Inheritance can be shown using UML class diagrams.

        Person

      |       |
    Pupil   Teacher

The arrow points towards the superclass.

This indicates that Pupil and Teacher inherit from Person.

Complete Working Example

```python linenums="1" class Person:

def __init__(self, name):
    self.name = name

def display_details(self):
    print("Name:", self.name)

class Pupil(Person):

def __init__(self, name, year_group):
    super().__init__(name)
    self.year_group = year_group

def display_details(self):
    print("Pupil:", self.name)
    print("Year group:", self.year_group)

class Teacher(Person):

def __init__(self, name, subject):
    super().__init__(name)
    self.subject = subject

def display_details(self):
    print("Teacher:", self.name)
    print("Subject:", self.subject)

pupil1 = Pupil("Alice", 6) teacher1 = Teacher("Mrs Smith", "Computing")

pupil1.display_details() print() teacher1.display_details()


Output:

```text
Pupil: Alice
Year group: 6

Teacher: Mrs Smith
Subject: Computing

Summary

Term Description
Superclass Parent class that provides properties and methods
Subclass Child class that inherits from another class
Inheritance Reusing properties and methods from another class
super() Calls the constructor of the superclass
Method Overriding Replacing an inherited method with a new version

Inheritance allows programmers to create specialised classes while reusing existing code.
